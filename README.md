# treboR

Öffentliche Linkseite: https://cheesylicious.github.io/trebor-links/

Dieses Repository enthält ausschließlich den statischen Website-Export.

## GitHub Pages

Unter Settings → Pages die Quelle „Deploy from a branch“, Branch `main` und Ordner `/(root)` auswählen.

## Aktualisieren

Die Website im treboR Linkpage Builder bearbeiten und exportieren. Die öffentlichen Dateien durch den neuen Export ersetzen. Keine `.trebor`-Projektdateien, Entwürfe oder internen Backups hochladen.
